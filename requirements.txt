## Gotchas that cost real time

# 1. Rust msvc ships NO linker. Without Build Tools every build dies with
#    "linker `link.exe` not found" while rustc --version looks perfectly healthy.
#    Only `cargo build` proves the toolchain. cargo finds link.exe via vswhere,
#    so it is deliberately not on PATH — do not "fix" that.
# 2. System default JDK is 26, which the Android Gradle Plugin rejects. JAVA_HOME
#    left alone on purpose; pin per-project in android/gradle.properties:
#      org.gradle.java.home=C:\\Program Files\\Eclipse Adoptium\\jdk-21.0.12.8-hotspot
# 3. cosign's winget alias is `cosign-windows-amd64`, and it wants
#    `cosign version`, not --version. Same for `go version`.
